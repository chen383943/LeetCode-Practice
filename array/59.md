<pre> ```class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        matrix = [[0] * n for _ in range(n)] #Getting a nxn matrix
        
        top, bottom = 0, n-1
        left, right = 0, n-1
        val = 1 # keep track of the layer 

        while left <= right: 
            # left to right 
            for col in range(left, right + 1): 
                matrix[top][col] = val 
                val += 1
            top += 1
        
            # top to bottom 
            for row in range(top, bottom + 1): 
                matrix[row][right] = val 
                val += 1
            right -= 1
            
            # right to left (reverse) 
            for col in range(right, left -1, -1): 
                matrix[bottom][col] = val
                val += 1
            bottom -=1
            
            # bottom to top (reverse)
            for row in range(bottom, top-1, -1): 
                matrix[row][left] = val
                val += 1
            left += 1
            
        return matrix
             ``` </pre>
