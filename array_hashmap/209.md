```{python}class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        left, right = 0, 0
        min_length = float('inf')
        n = len(nums)
        curr_sum = 0
        while right < n: 
            # base logic: keep tracking of the sum that is bigger than the target
            curr_sum += nums[right]
            while curr_sum >= target: 
                min_length = min(min_length, right - left + 1) # right - left + 1 keep track of the length of the sliding window
                curr_sum -= nums[left]
                left += 1
            right += 1 
        return min_length if min_length != float('inf') else 0
```
